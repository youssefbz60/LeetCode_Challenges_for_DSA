
# Two Sum

**LeetCode #1 | Easy | Array**

## Problem
Given an array of integers and a target, find the indices of two numbers whose sum equals the target.

## Example
```text
Input:  nums = [2, 7, 11, 15], target = 9
Output: [0, 1]
```

## Approach: Brute Force
- Use two nested loops to check pairs of elements.
- If their sum equals the target, return their indices.

## Complexity
- Time: O(n²)
- Space: O(1) auxiliary space (excluding the output array).

## What I Learned
- Array traversal using nested loops.
- Working with pointers and dynamic memory allocation in C.
- Returning an array from a function.
