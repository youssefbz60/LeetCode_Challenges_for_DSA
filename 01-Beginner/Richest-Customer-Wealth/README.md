
# Richest Customer Wealth

**LeetCode #1672 | Easy | 2D Array**

## Problem
Given a 2D array representing customers' bank accounts, return the maximum total wealth among all customers.

## Example
```text
Input:  accounts = [[1, 2, 3], [3, 2, 1]]
Output: 6
```

## Approach: Nested Loops
- Iterate through each customer.
- Calculate the total wealth by adding all their bank balances.
- Keep track of the maximum wealth.

## Complexity
- Time: O(m × n)
- Space: O(1).

## What I Learned
- Working with 2D arrays in C.
- Using nested loops to process matrix elements.
- Finding the maximum value while traversing an array.
